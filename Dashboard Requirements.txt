Dashboard Requirements:

1. Create minimum 2 pages  

2. KPI Cards
   - Total Sales
   - Total Quantity
   - Total Orders

3. Visuals to Include
   - Sales by Region
   - Sales by State
   - Category wise Sales
   - Payment Mode Analysis
   - Top 5 Products by Sales (Top N Filter)
   - Monthly / Date wise Sales Trend
   - Table Visual
   - Matrix Visual

4. Hierarchy
   Create hierarchy using:
   Region → State → Product

5. Tooltip
   Create one tooltip page and connect it to any visual.

6. Slicers
   Add slicers for:
   - Region
   - Category
   - Payment Mode

7. Clear All Slicers Button
   Add bookmark and clear filter button.

8. Edit Interactions
   Apply edit interactions between visuals.
   Example:
   - Clicking Region chart should filter other visuals.
   - Disable interaction for one visual and test.

9. Filters
   Apply:
   - Visual level filter
   - Page level filter
   - Report level filter

10. Formatting
   - Proper alignment
   - Data labels
   - Titles
   - Background colors
   - Visual formatting
   - Dashboard presentation

Insights Students Must Show in Dashboard:
- Which Region has highest sales
- Which State performs best
- Top selling products
- Most used payment mode
- Category contribution to sales
- Quantity sold by category
- Sales trend analysis
